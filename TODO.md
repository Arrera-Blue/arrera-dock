# Liste des tâches pour les prochaines versions

## Fonctionnalités & Comportement
- [ ] **Mode barre permanente** : Pouvoir forcer le dock en mode barre tout le temps (sans dépendre d'une fenêtre maximisée).
- [ ] **Alignement des icônes en mode étendu** : Pouvoir modifier l'emplacement des icônes (tout à droite / début, centré par défaut, ou personnalisé vers la fin).
- [ ] **Bouton Activités** : Ajouter un bouton « Activités » (avec option dans les paramètres pour l'activer ou le désactiver).
- [ ] **Aspect natif d'Activités** : Redonner le même aspect visuel à la partie Activités que par défaut dans GNOME Shell.

## Thème NeXTSTEP (Rétro / Tuiles 3D)
- [ ] **Option de thème dans GSettings** : Ajouter une clé de configuration (`dock-theme`) pour choisir entre le style actuel (`modern`) et `nextstep`.
- [ ] **Conteneur modulaire** : Adapter le conteneur du dock (classe CSS dynamique `.dock-theme-nextstep`) pour désactiver le flou/fond pilule et afficher les tuiles empilées.
- [ ] **Style des tuiles 3D biseautées (Tiles)** : Styliser les icônes en carrés nets sans arrondi avec relief 3D rétro (fond gris neutre, bordures biseautées claires haut/gauche et foncées bas/droite) et effet bouton enfoncé au clic.
- [ ] **Indicateurs d'applications ouvertes rétro** : Remplacer la pilule moderne par un repère NeXT (petite encoche, triangle ou 3 points discrets dans l'angle de la tuile).
- [ ] **Tuile Maître / Lanceur d'applications** : Adapter le bouton de la grille d'applications pour qu'il prenne l'apparence de la tuile principale NeXTSTEP en tête de dock.
